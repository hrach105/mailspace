# Mailspace for Windows

Multi-account Gmail, Calendar and Google Drive file-name search in one desktop app.

[Website](https://mailspace-desktop.neatshark1024.chatgpt.site/) · [Download Windows installer 0.2.3](https://github.com/hrach105/mailspace/releases/download/v0.2.3-beta/Mailspace-0.2.3-Setup.exe) · [Release notes and checksum](https://github.com/hrach105/mailspace/releases/tag/v0.2.3-beta)

## Start testing

1. Ask hrachkhachatryan1995@gmail.com to approve your Gmail addresses for testing.
2. Close the older app and install the Windows x64 beta. Choose **Only for me**.
3. Connect with Google and grant the Gmail checkbox on Google’s consent page. Calendar and Drive are optional.
4. Repeat for each approved account.

No Google Cloud project, API setup, or OAuth JSON import is needed by testers. Google public verification is not complete, so approved Test users are still required. The Windows build is unsigned.

Outgoing attachments support up to 20 files and 20 MB total including message text. Credentials, drafts and bounded cache are encrypted locally. Calendar and Drive are read-only.
